## 4. 本简历的取舍规则

**优先写**（面试最能展开）：
1. 名额超卖 + 分布式锁提前释放 → DB 唯一约束兜底（有完整闭环）
2. 订单状态机：非法跳转、超时关单、回调丢失卡单
3. 退款金额分摊 / 优惠冲抵 / 供应商结算对账（资损方向）
4. 接口自动化 45 个接口 + Jenkins，回归 110 → 65 分钟
5. 越权：供应商跨账号读取结算单
6. MQ 消费失败未重试导致卡单（2 处）

**弱化**：
- UI 自动化（Selenium 只留一句 + 8 条链路）
- 安全测试（并入越权条目，不单列 SQLMap 战绩）
- 造数脚本（一句带过 45 → 8 分钟）

**禁止**：
- Rust 及"自研压测工具"
- 进销存 / ETL / CRM 旧项目名
- "精通"
- 把旅游业务写成"电商商城秒杀"

## 5. 正式版 vs 线上版

- `site_full_show.md`：可写满，条目多、技术细节全，供 HR 与面试官细读。
- `resume_3y_oneline.md`：**不单列项目经历**，项目成果并入工作经历，每条只留结论 + 数字，第一屏必须出现岗位/年限/城市/学历/状态。
- 两版**数字与时间线必须完全一致**；改一版必须同步另一版。

## 6. 数字口径备注

- 用例数有两个口径：工作经历写 **600 + 条**（该模块累计维护），项目 1 写 **560 + 条**（本项目范围内）。同一份文件内不要混用，也不要再引入第三个数字。
- `5000 并发`、`45 接口 / 110→65 分钟`、`-41% / +60% / +30% / -40%`：全篇各只能出现一次。
