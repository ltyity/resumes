## 4. 本简历的取舍规则

**优先写**（面试最能展开）：
1. 站群配置化：YAML 模板、5 类模板复用、改版只改配置
2. 附件链路：PDF / Word / WPS / 扫描件（OCR）、正文清洗、失败进人工队列
3. 政策要素抽取：发文字号、发文机关、成文日期、效力状态、主题标签
4. 效力状态跟踪：回采原文状态 + 废止公告关联（业务价值最高的一条）
5. 增量与去重：栏目游标 + 时间回扫 + 夜间兜底；URL + 正文指纹
6. 招投标口径：金额单位归一、企业名称别名、转载去重
7. 合规：公开数据、单站 1 QPS、个人信息过滤

**弱化**：
- 反爬对抗（政策站风控弱，写太重反而假）
- 代理池、TLS 指纹、滑块（本版不写；如后续要投商业站再补）
- 大而全的技术栈罗列（Elasticsearch 只写"了解"）

**禁止**：
- Scrapy / Scrapy-Redis（本人不熟，且与"自研轻量调度"的答法冲突）
- Rust、"自研爬虫框架"这类无法深讲的表述
- 测试岗的项目名（AI 配餐、团期预订测试）和测试专属战绩（JMeter、SQLMap）
- "精通"、亿级数据量、千万级 QPS 等兜不住的表述
