### 简历格式
- 字体：思源黑体（基本无缺点、百搭无错、基本适用各种场合，无版权问题、可woff）、微软雅黑（好像细字有些不太好看，有些断，不让弄woff好像）、更纱黑体（等宽的总感觉不太好看，字母比较窄，可能不等宽的会好些）
- 正文字体大小：9pt（磅） = 小五号 = 12px（选择这个吧，能写更多的字，显得丰富）、10.5pt（磅） = 五号 = 14px
- 日期还是使用横杠吧，除了老鱼简历，wondercv和boos直聘都是使用的横杠；豆包推荐的格式： 2023.03 – 2023.08 豆包说有三种横杠，半角横杠- 和 中文破折号— 这个删除一个都不是，而是 – 这个才是 En dash（一字线）md中可以用 &ndash; 表示；win+. 找到Ω 找到 ?! 下面的那个短的细的就是了
- 工作经历、项目经历、教育经历 一律倒序
- 元素上下之间的margin会折叠（取最大的那个margin）而非叠加
- 熟练程度用词： 精通 ＞ 熟练掌握 ＞ 熟练使用 ＞ 掌握 ＞ 熟悉 ＞ 了解，还是不要使用精通这个词了，容易出问题，保守写熟练掌握总归是不会有大问题的。豆包说掌握这个词最好不要单独用，容易有歧义。
- prompt： 简历内容直白接地气点，不要弄得假高大上
- 写简历原则（感觉有的时候别的也适合）： 
    - 那就是你知道就写上，你知道就展示，你能做就利用。
    - 这就有点像"团结一切可以团结的力量"，既然你知道社招简历是这样写比较好，这样写是最好的，那就这样写，因为你知道，而小白不一定知道，别人不知道而你知道，这不也是一个能力吗，你不展示谁知道你有这种能力，哪怕别人知道，别人不敢写，而你敢写，不也是比别人强一点吗。有优势就展示。
    - 既然你能wz工作履历，知道wz个税流水什么的，那你为什么不利用这个优势呢，你不利用这个优势，那你跟那种真空窗的有什么区别，毫无区别。
    - 你有这种大的基础，和相关东西的学习能力，就应该说你全会。
- 工作经历、项目经历： 就三件事： 背景-动作-成果
- 使用 live server 插件实现热更新，备选可以使用 js 的循环逻辑实现轮训热更新
- 第一根线应该是 297- 底部 padding = 297-12 = 285，第二跟线应该是 285 + 297 - 第二个页面的上下 padding = 285 + 273 = 558 还有就是100%缩放的那个线才是准确的
- edge浏览器默认的边距好像是微小于10mm，但不是10mm，总体来的话
- 工作经历下 “主导核心模块全流程测试” 可选 参与 、 承担
